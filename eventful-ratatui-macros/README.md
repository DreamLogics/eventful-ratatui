# eventful-ratatui-macros

Procedural macros for [eventful-ratatui](https://crates.io/crates/eventful-ratatui):
`#[key_events]`, which binds key chords to eventful-rs events.

Use them through `eventful-ratatui`, which re-exports them; this crate's
version always matches it exactly.
